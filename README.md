# Manajemen Produk - Fundamental React

Aplikasi Manajemen Produk dibuat untuk memenuhi Tugas 3 mata kuliah Pemrograman Web.

## Deskripsi
Aplikasi ini digunakan untuk mengelola data produk menggunakan React.

## Fitur
- Menampilkan daftar produk
- Menambahkan produk
- Mengedit produk
- Menghapus produk
- Mencari produk berdasarkan nama

## Teknologi
- React
- JavaScript
- Vite
- CSS

## Konsep React yang Digunakan
- JSX
- Components
- Props
- useState
- Event Handling
- Conditional Rendering
- Rendering List menggunakan map() dan key

## Cara Menjalankan

Install dependencies:

npm install

Jalankan aplikasi:

npm run dev

Buka alamat lokal yang diberikan oleh Vite.
